## Установка

1. Клонируйте репозиторий:
'''
git clone https://github.com/SergeiVokhminov/DRF_homework.git
'''

2. Установите зависимости:
```
pip install -r requirements.txt
```

## Тестирование:

1. Для запуска подсчета покрытия тестами необходимо выполнить команду:
```
coverage run --source='.' manage.py test 
```

2. Чтобы вывести отчет по покрытию тестами, выполните команду:
```
coverage report
```

3. Покрытие тестами составляет 84 %

## Запуск проекта:

1. Откройте терминал
2. Запустите команду python manage.py runserver
